# Wakilni Marketplace (concept prototype)

A phone-first web app concept for Wakilni Marketplace, built for the ENTM 250K Wakilni Innovation Challenge.

## Put it online with GitHub Pages
1. Create a new public repository on GitHub (for example `wakilni-marketplace`).
2. Upload everything in this folder (keep the `img` and `icons` folders as they are).
3. In the repository go to **Settings > Pages**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then **Save**.
4. After a minute your app is live at `https://YOUR-USERNAME.github.io/wakilni-marketplace/`.

## Install it on a phone
- **iPhone (Safari):** open the link, tap Share, then **Add to Home Screen**.
- **Android (Chrome):** open the link, tap the menu, then **Install app** or **Add to Home screen**.

It opens full screen like an app, works offline after the first visit, and "Use my current location" works once the site is on https.

Store names, prices, ratings and reviews are sample data. Photos from Unsplash.
